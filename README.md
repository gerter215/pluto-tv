# 🪐 Pluto TV

برنامه وب **رایگان** تماشای فیلم و سریال، بهینه‌سازی‌شده برای **مرورگر تلویزیون‌های سامسونگ (Tizen)**.

> این پروژه نسخه وب اپلیکیشن CCloud است — چون تلویزیون سامسونگ اندروید نیست، اپ اندرویدی روی آن اجرا نمی‌شود؛ به جایش یک وب‌اپ سبک ساخته‌ایم که در مرورگر داخلی تلویزیون (و هر مرورگر دیگری) اجرا می‌شود.

---

## ✨ امکانات

- 🏠 **خانه**: جدیدترین فیلم‌ها، سریال‌ها و ردیف‌های ژانر
- 🎬 **فیلم‌ها / 📺 سریال‌ها**: فهرست با فیلتر (جدیدترین / سال ساخت / امتیاز IMDb) و بارگذاری بی‌نهایت
- 🔍 **جستجو**: صفحه‌کلید مجازی فارسی/انگلیسی مخصوص ریموت
- 📅 **فصل‌ها و قسمت‌ها**: انتخاب فصل و قسمت سریال‌ها
- 🎚 **انتخاب کیفیت**: منوی کیفیت/سورس داخل پخش‌کننده
- ❤️ **علاقه‌مندی‌ها**: ذخیره در حافظه تلویزیون (localStorage)
- 🌍 **کشورها**: مرور بر اساس کشور
- 🎮 **کنترل کامل با ریموت**: جهت‌ها، OK، دکمه بازگشت، پخش/توقف، جلو/عقب ۱۰ ثانیه
- 📺 **رابط ۱۰ فوتی**: فونت درشت، فوکوس واضح، تاریک‌پسند
- 🇮🇷 **فارسی و راست‌چین** با فونت وزیرمتن

## 🚀 دیپلوی روی Cloudflare Pages (رایگان)

> ⚠️ **مهم**: پروژه از Cloudflare Pages Functions استفاده می‌کند (پوشه `functions/` که مشکل CORS را حل می‌کند). روش «Drag & Drop در داشبورد» توابع را فعال نمی‌کند؛ حتماً از روش GitHub یا Wrangler زیر استفاده کنید.

### روش ۱ — اتصال به GitHub (ساده‌ترین و خودکار)

1. یک حساب رایگان در [dash.cloudflare.com](https://dash.cloudflare.com/sign-up) بسازید.
2. این پروژه را به یک ریپوی GitHub پوش کنید (یا یک ریپوی جدید بسازید و همه فایل‌ها را آپلود کنید).
3. در Cloudflare Pages → **Create** → **Pages** → **Connect to Git** → ریپو را انتخاب کنید.
4. تنظیمات build را خالی بگذارید (پروژه استاتیک است، build ندارد):
   - **Build command**: (خالی)
   - **Build output directory**: `/`
5. **Deploy** را بزنید. چند دقیقه بعد آدرس شما مثل `https://pluto-tv.pages.dev` می‌شود.
6. از این به بعد هر push به GitHub، خودکار دیپلوی می‌شود. 🎉

### روش ۲ — با Wrangler CLI

```bash
# نصب ابزار
npm install -g wrangler

# ورود به حساب Cloudflare
wrangler login

# رفتن به پوشه پروژه
cd pluto-tv

# دیپلوی (functions هم خودکار آپلود می‌شود)
wrangler pages deploy . --project-name pluto-tv
```

بعد از اولین دیپلوی، آدرس شما: `https://pluto-tv.pages.dev`

## 📺 استفاده روی تلویزیون سامسونگ

1. در تلویزیون، **مرورگر اینترنت (Internet)** را باز کنید.
2. آدرس `https://pluto-tv.pages.dev` را وارد کنید.
3. صفحه را **بوکمارک (ستاره)** کنید تا دفعه بعد راحت باز شود.
4. با ریموت کنترل کنید:
   - **جهت‌ها (▲▼◀▶)**: حرکت بین آیتم‌ها
   - **OK / Enter**: انتخاب و پخش
   - **بازگشت (Back)**: برگشت به صفحه قبل / خروج از پخش
   - **دکمه پخش/توقف ریموت**: پخش و توقف داخل پخش‌کننده
   - **جلو/عقب سریع**: جلو/عقب ۱۰ ثانیه

### نکات مهم برای تلویزیون

- ⚠️ **سورس‌های `mkv`** ممکن است در مرورگر تلویزیون پخش نشوند. از منوی **کیفیت** یک سورس `mp4` یا `webm` انتخاب کنید (سورس‌های قابل پخش اول لیست می‌شوند).
- ⚠️ بعضی سورس‌ها `http` هستند؛ اپ اول نسخه `https` را امتحان می‌کند و اگر جواب نداد به `http` برمی‌گردد.
- اگر صفحه سفید ماند، یک بار دکمه **بازگشت** را بزنید یا کش مرورگر را پاک کنید.
- دکمه **تنظیمات ⚙️** → **پاک‌کردن کش** برای رفع مشکلات نمایش.

## 🧪 اجرای محلی (تست روی کامپیوتر)

```bash
cd pluto-tv
node dev-server.js 8080
```

سپس در مرورگر: `http://localhost:8080`

> سرور محلی هم پروکسی API را شبیه‌سازی می‌کند، پس همه امکانات همان‌طور که روی Cloudflare کار می‌کند، محلی هم کار می‌کند.

## 🔧 تنظیمات فنی

| تنظیم | مقدار |
|---|---|
| سرور اصلی API | `server-hi-speed-iran.info` |
| سرورهای کمکی | `hostinnegar.com`, `windowsdiba.info` |
| کش پروکسی | ۵ دقیقه (کاهش فشار روی سرور) |

اگر سرور API عوض شد، فقط `js/config.js` را ویرایش کنید.
